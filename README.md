Pet-проект
Дипломная работа по курсу DevOps.

## Тема проекта

SaaS-платформа для управления фитнес-тренировками.

Идея — создать облачное приложение, где тренеры и клиенты смогут взаимодействовать онлайн.
Тренеры смогут составлять тренировочные программы, добавлять расписание занятий и следить за прогрессом клиентов.
Клиенты, в свою очередь, смогут записываться на тренировки, просматривать свои планы и статистику, отмечать выполненные занятия и получать обратную связь от тренеров.

Основная цель — показать, как с нуля собрать и задеплоить приложение, применяя DevOps-инструменты.

Планирую реализовать:

серверную часть на Python, фронтенд на HTML, CSS и JavaScript;
базу данных PostgreSQL для хранения пользователей, тренировок и расписания;
контейнеризацию через Docker и запуск с Docker Compose;
CI/CD с Jenkins (автоматическая сборка и деплой);
развертывание приложения в облаке на Linux‑серверах с Nginx;
оркестрацию через Kubernetes;
автоматизацию инфраструктуры с помощью Terraform и Ansible;
базовый мониторинг, логирование и резервные копии БД.
